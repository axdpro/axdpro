A package for single X-ray diffraction automations: Click the link under repository axdpro->About to download the package (see 'axdpro_kylin_install_readme.pdf' for a brief readme).
Install: After saving the sgxpro.tar to a folder where to put the package, type command: 
         tar  xvf  sgxpro.tar; ./sgxpro_install
